EG2: lifting State Up Example:
problem:
let's say you have two input fields in the children components, and you want to keep track of the values of both inputs in the parent component. When you change the value in ChildA, you need to reflect that change in the parent and update the value in ChildB. How do we do this?

Sol) In React, lifting state up refers to moving the state management from a child component to the parent component so that multiple child components can share and interact with the same state.

HOW TO LIFT STATE UP?
1. identify the state that needs to be shared: This is the data that will be shared or controlled by parent 
2. Move the state to the parent component: in parent component create state using useState
3. Pass the state down to child component as props 
4. Pass the setter function down as prop to update the state.

Ex:
const ParenComp = () => {
  const [inputValue, setInputValue] = useState('');
  return (
    <div>
      <ChildA value={inputValue} onChange={setInputValue}/>
      <ChildB value={inputValue} /> // Ab agr A me change krege to automatically B me bhi hoga change
    </div>
  )
}

const ChildA = ({value, onChange}) => {
  return (
    <label> Input from child A </label>
    <input type="text" value={value} onChange={(e) => onChange(e.target.value)} /> // Idr se OnChange me data pass ho raha hai 
  )
}

const ChildB = ({value}) => {
  return (
    <div> 
      <label>Input from ChildB</label>
      <input type="text" value={value} readOnly/>
    </div>
  )
}

  sol) BY using "CONTEXT", So by using react context, we can avoid prop drilling

---------------------------------------------------- BETTER WAY TO USE THE USE CONTEXT --------------------------------------------------------

STEPS:

1. Create Context: This will be the object that hold your state and provide it to component. 
2. Create A context Provider: provider will be used to wrap your app and pass the state to the component 
3. Use the context in child component: Inside component that needs the global state, you will use the useContext hook to access the state \
4. update the context state: you can update the state in your provider and it will be reflected all accross the components that consume that context. 


Ex:
step 1: create UserContext.js -> First, create a new file called UserContext.js to define your context and provider.

import React, { createContext, useState } from 'react';

// Create a context for user data
const UserContext = createContext();

// Create a provider component
const UserProvider = ({ children }) => {
  // Define the initial state (you can set it as null or with any user data)
  const [user, setUser] = useState({
    name: 'John Doe',
    email: 'john@example.com',
  });

  // The provider component will pass the state and updater function to the rest of the app
  return (
    <UserContext.Provider value={{ user, setUser }}>
      {children}
    </UserContext.Provider>
  );
};

export { UserContext, UserProvider };


-----

Step 2: Wrap the App with the Provider

-> Now that we have the context and provider, we need to wrap the entire app with the UserProvider. This ensures that any component in your app can access the UserContext.
-> In index.js or App.js, wrap your app with the UserProvider:

import React from 'react';
import ReactDOM from 'react-dom';
import App from './App';
import { UserProvider } from './UserContext';  // Import the provider

// Wrap the entire app with UserProvider
ReactDOM.render(
  <UserProvider>
    <App />
  </UserProvider>,
  document.getElementById('root')
);

-----

Step 3: Consume the Context in Child Components

-> Now, inside any component that needs access to the user state, you can use the useContext hook to read and update the state. 

import React, { useContext } from 'react';
import { UserContext } from './UserContext';  // Import the context

const UserProfile = () => {
  // Use the useContext hook to access the user state
  const { user, setUser } = useContext(UserContext);

  const updateUser = () => {
    // Update the user state using the setUser function
    setUser({
      name: 'Jane Doe',
      email: 'jane@example.com',
    });
  };

  return (
    <div>
      <h2>User Profile</h2>
      <p>Name: {user.name}</p>
      <p>Email: {user.email}</p>
      <button onClick={updateUser}>Change User</button>
    </div>
  );
};

export default UserProfile;

Managing Multiple States with useContext like For Theme, User Authentication, Language Preference

Step1: Create a Context with Multiple States

import React, { createContext, useState } from 'react';

// Create the Context for multiple states
const AppContext = createContext();

const AppProvider = ({ children }) => {
  // Define multiple states
  const [theme, setTheme] = useState('light');
  const [isAuthenticated, setIsAuthenticated] = useState(false);
  const [language, setLanguage] = useState('en');

  // Functions to update these states
  const toggleTheme = () => {
    setTheme((prevTheme) => (prevTheme === 'light' ? 'dark' : 'light'));
  };

  const login = () => {
    setIsAuthenticated(true);
  };

  const logout = () => {
    setIsAuthenticated(false);
  };

  const changeLanguage = (newLanguage) => {
    setLanguage(newLanguage);
  };

  return (
    <AppContext.Provider
      value={{
        theme,
        isAuthenticated,
        language,
        toggleTheme,
        login,
        logout,
        changeLanguage,
      }}
    >
      {children}
    </AppContext.Provider>
  );
};

export { AppContext, AppProvider };

import React, { useContext } from 'react';
import { AppContext } from './AppProvider';

const Dashboard = () => {
  const {
    theme,
    isAuthenticated,
    language,
    toggleTheme,
    login,
    logout,
    changeLanguage,
  } = useContext(AppContext);

  return (
    <div style={{ backgroundColor: theme === 'light' ? '#fff' : '#333', color: theme === 'light' ? '#000' : '#fff' }}>
      <h1>{isAuthenticated ? 'Welcome Back!' : 'Please Log In'}</h1>
      <p>Current Language: {language === 'en' ? 'English' : 'Español'}</p>
      <button onClick={toggleTheme}>Toggle Theme</button>
      {!isAuthenticated ? (
        <button onClick={login}>Log In</button>
      ) : (
        <button onClick={logout}>Log Out</button>
      )}
      <button onClick={() => changeLanguage(language === 'en' ? 'es' : 'en')}>
        Switch Language
      </button>
    </div>
  );
};

export default Dashboard;
