3. Create Slice (cart slice)

import { createSlice } from "@reduxjs/toolkit";

const cartSlice = createSlice({
  name: "cart",
  initialState: {
    items: [],
  },
  reducers: {
    addItem: (state, action) => {
      // addItemToCart is basically "ACTION",
      // Reducer function is the arrow function (jo hum use kr rahe hai)
      // so jo reducer function hai isme logic to update our state.
      // Here we are Mutating the state
      state.items.push(action.payload);
    },
    removeItem: (state) => {
      // write the logic properly, multiple items honge to action.payload filter krke remove krege
      state.items.pop();
    },
    clearCart: (state) => {
      state.items.length = 0;
    },
  },
});

export const {addItem,removeItem,clearCart} = cartSlice.actions;
export default cartSlice.reducer; 

Note: 
1. This createSlice function will return the Object in the cartSlice 
2. cartSlice object will look like 
{
    actions: {
        addItem,
        removeItem
    },
    reducer
}

3. We can not do like this "state.items = [];"

NOTE: 

1. when we are doing selector (make sure we are doing the right portion of the store)
 // WRONG -> useSelector((store) => store); // idr sare store ko subscribe kr rahe hai, Kahin par bhi agr change hoga to idr get krega, which is big performance loss. 
 // RIGHT -> useSelector((store) => store.cart.items); // here we are subscribing small portion of store, so jo items change honge tabhi ye subscribe hoga bass..
